# InfoWeaver

🔎 InfoWeaver

An AI-powered research assistant that weaves insights from multiple sources.

📌 Overview

InfoWeaver is an AI-powered research tool built with Streamlit, LangChain, and the Groq API.
It combines knowledge from multiple sources (Arxiv, Wikipedia, and DuckDuckGo) to deliver concise, reliable answers to user queries.

Whether you’re exploring academic papers, looking for general knowledge, or scanning the web for updates, InfoWeaver integrates these sources into a single seamless interface.

⸻

✨ Features
	•	🔍 Multi-source search → Queries Arxiv, Wikipedia, and DuckDuckGo in one place.
	•	⚡ Groq-powered LLM → Ultra-fast reasoning and natural language responses.
	•	📚 Arxiv integration → Quickly retrieve the latest research papers.
	•	🌐 Wikipedia wrapper → Get concise encyclopedic knowledge.
	•	🔎 DuckDuckGo search → Fetch general web results for broader coverage.
	•	🖥️ Streamlit UI → Simple, interactive frontend for users.

⸻

🛠️ Tech Stack
	•	Frontend/UI → Streamlit
	•	LLM Backend → Groq API
	•	Orchestration → LangChain Agents
	•	Knowledge Sources → Arxiv API, Wikipedia API, DuckDuckGo Search
